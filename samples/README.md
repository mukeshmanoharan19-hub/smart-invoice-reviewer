# Sample invoices

`samples/generated/` contains fictional PDF invoices for manual demos. There is no committed ground-truth manifest in this OpenAI-only build; drag a PDF into the browser to exercise the workflow.

To exercise the receipt path, upload your own PNG or JPEG receipt during the manual walkthrough.

Never add private documents or random internet scrapes to this repository. GSTIN values used in demos must remain fictional checksum examples and are never presented as verified business registrations.
